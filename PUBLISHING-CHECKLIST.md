# Before publishing to GitHub

- [ ] Check the original repository's licence and attribution requirements.
- [ ] If no licence is provided, do not assume the code can be redistributed; ask the author for permission or create your own implementation.
- [ ] Keep the dataset out of Git history (`data/` is ignored).
- [ ] Run the notebook end-to-end and verify the outputs.
- [ ] Add your own documented contribution only after implementing and testing it.
- [ ] Do not claim the original author's work or results as your own.
